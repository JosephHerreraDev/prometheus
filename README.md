## Installation
    
```bash
curl -sSL https://raw.githubusercontent.com/JosephHerreraDev/prometheus/main/boot.sh | bash
```

> [!WARNING]
> This is only for a fresh arch linux install, with the selection of hyprland from archinstall

## Features

- Hyprland window manager
- Theme switching
- Total personalization
- Quickshell based
